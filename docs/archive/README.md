# Documentation archive

Esta carpeta conserva planes, auditorías y reportes completados. Su contenido explica la evolución del
proyecto, pero **no describe necesariamente el estado actual** y no debe usarse como guía de desarrollo u
operación.

Las fuentes vigentes son `README.md`, `CHANGELOG.md` y los documentos temáticos en `docs/`.

## Clasificación

- `audits/`: auditorías y revisiones sustituidas.
- `migrations/`: planes y evidencias de modernizaciones completadas o parciales.
- `module-refactors/`: bitácoras de refactorización por módulo.
- `reports/`: reportes puntuales ya consolidados.

Los nombres originales se conservan para mantener trazabilidad.
